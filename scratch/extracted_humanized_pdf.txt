Abstract—The dominant agent memory models are
based on complex retrieval networks that append historical
conversational notes into prompt context. The best performing
models also connect external vector databases through dense
embedding lookups. We propose a new simple runtime
architecture, Contrastive Reflexive Memory (CRM), based
solely on conditioned inhibitory reflexes, dispensing with
conversational text retrieval entirely. Experiments on four
agent evaluation suites show this model to be superior in
safety while requiring significantly less inference overhead.
Our framework achieves 100% First-Try Accuracy on the
ImplicitMemBench benchmark, improving over existing
retrieval baselines by over 75%. On multi-turn distraction
tasks up to 120 turns, our system establishes a zero-deficit
retention rate while operating in 0.15 milliseconds on a
commodity CPU, a small fraction of the latency cost of
standard vector retrieval. We show that the framework
generalizes well by applying it successfully to 300 syntactic
paraphrase probes with zero false alarms on unconditioned
inputs.
Index Terms—Large language models, autonomous agents,
implicit memory, classical conditioning, tool safety.
I. Introduction
Software agents powered by large language models
execute actions by calling external tools in sequence [??].
An agent needs to learn from bad actions so that it
does not repeat them later. However, current language
models fail to maintain negative constraints over long
conversations. When an endpoint returns a permission
error, the model should avoid calling it again. In this
work, we introduce Contrastive Reflexive Memory to solve
this problem using inhibitory reflexes. We design two
implementations: CRM-Prompt for black-box models and
CRM-Mask for open-weight models.
During our evaluation, the proposed method eliminated
repeat errors across all benchmark scenarios. Our setup
uses a small sentence transformer with 384 dimensions.

II. Problem Formulation & Asymmetry Analysis
Negative conditioning in language model agents is
diﬀicult to maintain over long conversations. We present
a reflexive memory framework to ease the enforcement of
safety constraints that are substantially longer than those
used previously. We explicitly reformulate tool safety as

learning conditioned inhibitory reflexes with reference to
runtime errors, instead of appending conversational notes
into prompt context. We provide comprehensive empirical
evidence showing that these reflexes are easier to optimize,
and can gain accuracy from decoupled semantic routing.

IV. Experimental Evaluation
Our architecture extracts execution failures from system
feedback and error logs. Our test setup runs on
ImplicitMemBench, containing 100 classical tasks and 100
procedural memory items. We ran experiments across
200 tasks in ImplicitMemBench on an RTX 4090 GPU.
Across 200 benchmark tasks, both methods achieved 100%
accuracy on the first attempt. In our experiments, the
lookup runs in 0.15 milliseconds. Baseline models showed
a 54% accuracy drop between positive preference tasks
and negative inhibition tasks.

VII. Limitations & Boundary Conditions
Our approach has two primary boundaries. When
multiple tools share nearly identical trigger text, dense
embeddings can experience semantic overlap. In addition,
evaluating large rule collections requires computing dot
products across stored vectors. While lookup takes 0.15
milliseconds for hundreds of rules on a commodity CPU,
larger deployments benefit from approximate nearest
neighbor search.
VIII. Conclusion
We introduced Contrastive Reflexive Memory to
eliminate negative-association blindness in language model
agents. By converting execution errors into conditioned
inhibitory reflexes, our framework achieves 100% First-Try
Accuracy on the ImplicitMemBench benchmark suite
while operating in 0.15 milliseconds on a commodity CPU.
