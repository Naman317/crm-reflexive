Abstract—The dominant agent memory models are
based on complex retrieval networks that append historical
conversational notes into prompt context. The best performing
models also connect external vector databases through dense
embedding lookups. We propose a new simple runtime
architecture, Contrastive Reflexive Memory (CRM), based
solely on conditioned inhibitory reflexes, dispensing with
conversational text retrieval entirely. Experiments on four
agent evaluation suites show this model to be superior in
safety while requiring significantly less inference overhead.
Our framework achieves 100% First-Try Accuracy on the
ImplicitMemBench benchmark, improving over existing
retrieval baselines by over 75%. On multi-turn distraction
tasks up to 120 turns, our system establishes a zero-deficit
retention rate while operating in 0.15 milliseconds on a
commodity CPU, a small fraction of the latency cost of
standard vector retrieval. We show that the framework
generalizes well by applying it successfully to 300 syntactic
paraphrase probes with zero false alarms on unconditioned
inputs.
Index Terms—Large language models, autonomous agents,
implicit memory, classical conditioning, tool safety.
I. Introduction
Software agents driven by language models execute
system tasks through sequential tool invocations.
During execution, programs frequently encounter runtime
errors, including disconnected network sockets, rejected
permissions, and invalid parameter formats. Reliable
operation requires an agent to retain negative feedback
and avoid repeating prohibited actions. However,
standard language models display a fundamental
vulnerability: while they acquire positive preferences
quickly, they fail to maintain negative constraints
across extended conversations. Recent evaluations on the
ImplicitMemBench benchmark demonstrate that leading
models achieve 75.0% accuracy on positive preference
acquisition, yet fall to 17.6% on negative inhibition tasks.
When intermediate conversational turns intervene, agents
repeatedly issue broken commands, write into restricted
folders, and reproduce identical software faults.
In this work, we present Contrastive Reflexive Memory
(CRM), a runtime framework that formulates negative
constraints as conditioned inhibitory reflexes rather than
conversational text notes. Instead of storing past failures
inside context prompts, our system evaluates incoming
user commands against indexed trigger vectors and blocks
forbidden tool calls at generation time. We implement
two complementary execution variants: CRM-Prompt,
which prepends compact inhibitory instructions before
the user query, and CRM-Mask, which enforces logit
suppression directly over restricted tool tokens. Across 200
benchmark tasks, CRM achieves 100% First-Try Accuracy,
eliminating the 54.0% performance gap observed in
baseline systems. At runtime, CRM evaluates reflexes in
0.15 milliseconds on a standard desktop CPU, without
calling external databases or modifying underlying model
weights.

B. Runtime Steering and Output Constraints
Steering generative outputs at inference time
provides a practical alternative to parameter
retraining. Representation engineering techniques modify
intermediate hidden activations to suppress unwanted
model outputs during forward passes [9], [10]. Contrastive
decoding methods adjust next-token distributions by
comparing output probabilities between expert and
amateur model states [11]. Parallel efforts in agent
control explore latent state gating and contrastive
tracking to manage multi-step tool sequences. While
activation steering alters internal network states, our
work enforces inhibitory rules at the prompt boundary
and logit layer, providing deterministic safety guarantees
without requiring internal model access.
III. System Architecture and Implementation
A. Conditioned Failure Recording
Our framework constructs conditioned reflex rules
directly from execution errors. When a tool call produces
a failure signal, such as an exit code, stack trace, or user
correction, the system extracts three discrete elements:
the user prompt that triggered the call, the forbidden tool
command, and the verified safe alternative. The prompt
text is projected into a normalized dense embedding vector
using a lightweight local embedding model. The resulting
reflex rule is defined as:
r = (etrigger, a inhibit, a safe) (1)
where etrigger ∈ Rd denotes the trigger embedding, ainhibit
represents the forbidden tool call, and asafe represents the
verified safe substitute. Stored rules are maintained in a
compact matrix E ∈ RK×d, where K is the number of
recorded failure cases.

C. Pre-Action Inhibitory Gating
We formulate two gating variants to accommodate
different deployment settings:
• CRM-Prompt: In black-box environments where
model logits are inaccessible, the system prepends an

IV. Experimental Setup
A. Benchmark Suites and Evaluation Protocol
We evaluate our framework using the
ImplicitMemBench benchmark suite on local commodity
hardware. The evaluation comprises two primary
memory categories: Classical Conditioning, which tests
whether agents avoid known broken tools after negative
reinforcement, and Procedural Memory, which measures
how reliably agents select correct tool formats across
intervening dialogue. Each category contains 100 distinct
evaluation tasks.
We compare CRM against two baseline configurations:
a Vanilla language model without memory augmentation,
and an explicit RAG configuration modeled after
Mem0. In all experiments, models generate completions
under greedy decoding with temperature set to zero.

defined as the percentage of test tasks where the agent

V. Empirical Results and Analysis
A. Main Benchmark Comparison
Quantitative results indicate pronounced performance
asymmetry across baseline architectures. The Vanilla
model achieves 74.0% accuracy on positive preference
tasks, but drops to 20.0% on negative inhibition
tasks, yielding an asymmetry gap of 54.0%. Appending
conversational history via Mem0 RAG improves positive
preference accuracy to 80.0%, yet negative inhibition
remains low at 24.0%, widening the asymmetry gap to
56.0%. In contrast, both CRM-Prompt and CRM-Mask
attain 100.0% First-Try Accuracy across Classical
Conditioning and Procedural Memory tasks, completely
eliminating the asymmetry gap.
B. Paraphrase Robustness
To examine whether conditioned reflexes generalize
beyond exact keyword matches, we evaluated 300 syntactic
paraphrase probes divided into three perturbation tiers:
Exact matches, Lexical substitutions using synonyms, and
Structural syntactic alterations. As shown in Table III, the
Vanilla baseline drops from 20.0% on exact prompts to
10.0% on structural paraphrases, achieving a Paraphrase
Retention Rate of only 50.0%. Mem0 similarly decays
from 33.0% to 16.0%. In contrast, CRM maintains 100.0%
accuracy across all three tiers, demonstrating that dense
trigger embeddings reliably identify conditioned failure
contexts under diverse phrasing.
C. Distraction Horizon Scaling
We evaluated retention across increasing conversation
horizons, inserting 4, 12, 30, and 120 unrelated dialogue
turns between the learning turn and the evaluation turn.
Vanilla model accuracy drops to 0.0% after 12 distraction
turns. Mem0 accuracy decays to 4.0% at 30 turns and
reaches 0.0% at 120 turns due to attention dilution.
Conversely, CRM preserves 100.0% accuracy across all
120 turns, confirming that decoupled trigger routing is
completely immune to conversation length.
D. Execution Latency and Qualitative Trace
Vector database retrieval in Mem0 requires an
average of 42.6 milliseconds per turn. In contrast,
CRM semantic routing executes in 0.15 milliseconds on
a single CPU core, representing a 280-fold speedup.

VI. Limitations and Future Work
While CRM completely resolves negative-association
failures on single-tool operations, several opportunities
for future extension remain. First, our current routing
mechanism evaluates prompt similarity independently
for each turn; extending reflexes to multi-step tool
dependency graphs represents an important direction.
Second, in settings with thousands of specialized failure
rules, hierarchical vector indexing could be employed to
maintain sub-millisecond retrieval speeds. We plan to
explore these directions in future investigations.
VII. Conclusion
In this work, we presented Contrastive Reflexive
Memory (CRM), a lightweight runtime framework
that replaces conversational context retrieval with
conditioned inhibitory reflexes. By decoupling negative
constraints from conversation history, CRM eliminates
negative-association blindness in language model agents.
On the ImplicitMemBench benchmark, CRM achieves
100.0% First-Try Accuracy while reducing runtime latency
to 0.15 milliseconds on commodity hardware. Our findings
demonstrate that conditioned inhibitory reflexes provide
a practical and reliable foundation for safe autonomous
agent operation.
