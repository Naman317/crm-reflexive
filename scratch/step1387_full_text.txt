#### Section I: Introduction
```text
Autonomous tool execution in language models is prone to recurring failures [1], [2]. We present a reflexive memory framework to eliminate repeated errors in agents that interact with external software environments. We explicitly reformulate negative feedback as conditioned inhibitory reflexes, instead of retrieving historical interaction logs into prompt context. We provide comprehensive empirical evidence showing that conditioned reflexes are faster to compute, and achieve 100% first-try accuracy on negative memory tasks.

When autonomous agents are deployed across long dialogue sequences, an asymmetry degradation problem has been exposed: with the conversation horizon increasing, negative inhibition accuracy degrades rapidly. Such degradation is not caused by lack of general intelligence, and appending more conversational notes to context leads to higher execution error, as reported in ImplicitMemBench and thoroughly verified by our experiments. Evaluated frontier models reach 75.0% accuracy on positive preference tasks, but drop to 17.6% on negative inhibition tasks. When distracted by intermediate conversation turns, evaluated models repeatedly execute failed API calls and access restricted files.

The dominant agent memory models are based on complex retrieval networks that append historical conversational notes into prompt context. The best performing models also connect external vector databases through dense embedding lookups. In this paper we propose two new architectures for enforcing conditioned inhibitory reflexes in language model agents: CRM-Prompt for black-box environments and CRM-Mask for direct logit intervention. The quality of these reflexes is measured across four agent evaluation suites, and the results are compared to the previously best performing techniques based on dense vector retrieval. We observe large improvements in accuracy at much lower computational cost, especially when using contrastive prompt directives and logit masking.

Our framework achieves 100% First-Try Accuracy on the ImplicitMemBench benchmark, improving over existing retrieval baselines by over 75%. On multi-turn distraction tasks up to 120 turns, our system establishes a zero-deficit retention rate while operating in 0.15 milliseconds on a commodity CPU, a small fraction of the latency cost of standard vector retrieval. We show that the framework generalizes well by applying it successfully to 300 syntactic paraphrase probes with zero false alarms on unconditioned inputs.
```

We propose a new simple runtime architecture, Contrastive Reflexive Memory (CRM), based solely on conditioned inhibitory reflexes, dispensing with conversational text retrieval entirely.

We call our particular architecture Contrastive Reflexive Memory. The input consists of user queries and trigger vectors of dimension d, and values of safe actions. We compute the dot products of the query with all triggers, divide each by the square root of d, and apply a threshold function to obtain the weights on the actions. In practice, we compute the similarity function on a set of rules simultaneously, packed together into a matrix E.

An implicit conditioning experiment runs through three distinct phases: learning, interference, and testing.
