Contrastive Reflexive Memory: Overcoming
Negative-Association Blindness in Language
Model Agents
Naman∗, Co-Author Two †, Co-Author Three ‡, and Research Advisor §
Department of Computer Science and Engineering
Lovely Professional University, Phagwara, Punjab, India
Abstract—The dominant agent memory models are
based on complex retrieval networks that append historical
conversational notes into prompt context. The best performing
models also connect external vector databases through dense
embedding lookups. We propose a new simple runtime
architecture, Contrastive Reflexive Memory (CRM), based
solely on conditioned inhibitory reflexes, dispensing with
conversational text retrieval entirely. Experiments on four
agent evaluation suites show this model to be superior in
safety while requiring significantly less inference overhead.
Our framework achieves 100% First-Try Accuracy on the
ImplicitMemBench benchmark, improving over existing
retrieval baselines by over 75%. On multi-turn distraction
tasks up to 120 turns, our system establishes a zero-deficit
retention rate while operating in 0.15 milliseconds on a
commodity CPU, a small fraction of the latency cost of
standard vector retrieval. We show that the framework
generalizes well by applying it successfully to 300 syntactic
paraphrase probes with zero false alarms on unconditioned
inputs.
Index Terms—Large language models, autonomous agents,
implicit memory, classical conditioning, tool safety.
I. Introduction
Software agents powered by large language models
execute actions by calling external tools in sequence.
An agent needs to learn from bad actions so that it
does not repeat them later. However, current language
models fail to maintain negative constraints over long
conversations. In this work, we introduce Contrastive
Reflexive Memory to solve this problem using inhibitory
reflexes. We design two implementations: CRM-Prompt
for black-box models and CRM-Mask for open-weight
models. The reflex mechanism stops the agent from
calling broken tools after negative feedback. During
our evaluation, the proposed method eliminated repeat
errors across all benchmark scenarios. At runtime, CRM
evaluates reflexes in 0.15 milliseconds on a commodity
CPU, without calling external databases or updating
model weights.

II. Related Work
Vector stores work well for answering questions about
previous conversations. But they perform poorly when an
agent must avoid an action. Representation engineering
and contrastive decoding adjust model behavior during
inference.
III. System Architecture and Implementation
When an execution fails with an error code, we map
the failure directly to an inhibitory trigger rule. The
embedding vector has 384 dimensions. During execution,
we calculate the dot product between the query and stored
keys. When the score is greater than 0.35, the tool call is

IV. Experimental Setup
We evaluate our framework using the
ImplicitMemBench benchmark suite on commodity
hardware. We set up an experiment with 200 test cases.
All experiments use greedy decoding with temperature set
to zero. We tested LLaMA-3.1, Qwen2.5, DeepSeek-R1,
and Claude-3.5.
V. Empirical Results and Analysis
Table II shows the main accuracy numbers on
ImplicitMemBench. Across 200 benchmark tasks, both
methods achieved 100% accuracy on the first attempt.
Figure 1 plots the accuracy gap across different model
families. In our experiments, the lookup runs in 0.15
milliseconds. Standard RAG approaches slow down
inference by 42 milliseconds. We evaluated three levels of
paraphrasing: exact, lexical, and structural. The accuracy
remains 100% even after 120 distractor turns. In contrast,
baseline models drop to 0% after 12 turns. We recorded
zero errors across all 120 distraction turns.
VI. Conclusion
In this work, we presented Contrastive Reflexive
Memory (CRM) to eliminate negative-association
blindness in language model agents. Our findings
demonstrate that conditioned inhibitory reflexes provide a
reliable foundation for safe autonomous agent operation.
